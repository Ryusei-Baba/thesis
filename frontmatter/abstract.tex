\begin{center}
  \scalebox{1.5}{物体追跡導入による}\\
  \scalebox{1.5}{リアルタイム・ゼロショットセグメンテーション}\\
  {--- 自律走行モビリティにおける認識・判断タスクへの応用 ---}
\end{center}
\vspace{1.0zh}

近年，自然言語の指示に基づき対象を切り出すゼロショットセグメンテーション技術が注目されている．しかし，大規模な基盤モデルを用いるこれらの技術は，高頻度で処理を繰り返すとシステム全体の処理速度が遅くなる問題がある．本研究では，ゼロショットセグメンテーションのリアルタイム性を向上するために，高コストな物体検出処理の頻度を削減し，その間を軽量な物体追跡で補間する手法を提案する．具体的には，テキストプロンプトに基づきGrounding DINOで物体検出を行い，SAM2でセグメンテーションマスクを生成する．その後のフレームでは，Shi-Tomasi法に基づき特徴点を抽出し，Lucas-Kanade法に基づくピラミッドオプティカルフローで追跡することで，物体の位置と大きさを更新する．これにより，検出とセグメンテーションの処理頻度を削減し，システム全体のスループットを向上させる．さらに，本手法を自律走行モビリティにおける認識・判断タスクへ応用し，実環境への適用可能性を調査する．実環境における消失点ナビゲーションおよび障害物検出・停止タスクの実験を通じて，提案手法が実モビリティに適用可能か調査する．本研究の成果は，リアルタイムな認識が求められる様々な応用分野に貢献することが期待される．

\chapter*{abstract}
\thispagestyle{empty}
%
\begin{center}
  \scalebox{1.3}{Real-time Zero-shot Segmentation through Object Tracking}\\
  {--- Application to Perception and Decision-making Tasks in Autonomous Mobility ---}
\end{center}
\vspace{1.0zh}
%
% 英語版概要

Recently, zero-shot segmentation technology that extracts objects based on natural language instructions has gained attention. However, these technologies using large-scale foundation models have a problem of slowing down the overall system processing speed when processing is repeated at high frequency. In this study, we propose a method to improve the real-time performance of zero-shot segmentation by reducing the frequency of high-cost object detection processing and interpolating the intervals with lightweight object tracking. Specifically, object detection is performed using Grounding DINO based on text prompts, and segmentation masks are generated using SAM2. In subsequent frames, feature points are extracted based on the Shi-Tomasi method and tracked using the pyramid optical flow based on the Lucas-Kanade method to update the position and size of the object. This reduces the processing frequency of detection and segmentation, improving the overall system throughput. Furthermore, we apply this method to perception and decision-making tasks in autonomous mobility and investigate its applicability to real-world environments. Through experiments on vanishing point navigation and obstacle detection and stopping tasks in real environments, we investigate whether the proposed method can be applied to real mobility. The results of this study are expected to contribute to various application fields that require real-time recognition.


Keywords: Zero-shot segmentation, Object tracking, Autonomous mobility
