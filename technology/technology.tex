本章では，本研究の基盤となる要素技術について述べる．まず，大規模基盤モデルの概念とその特徴を説明し，次にゼロショット物体検出およびゼロショットセグメンテーションの技術について詳述する．

\section{大規模基盤モデル}
大規模基盤モデル（Foundation Model）とは，大量かつ多様なデータで事前学習された汎用的な機械学習モデルであり，特定のタスクに対して追加学習やプロンプトのみで適応可能な能力を持つ．この技術は，一つのモデルが複数のタスクに対応できる点で，従来のタスク特化型モデルとは根本的に異なる．

大規模基盤モデルの技術的基盤は，Transformer アーキテクチャと自己教師あり学習の組み合わせにある．Transformer は，self-attention 機構により入力データの長距離依存関係を効率的にモデル化する．具体的には，入力シーケンスの各要素が他のすべての要素との関連性を計算し，重要な情報を選択的に抽出する．自己教師あり学習は，人手によるラベル付けを必要とせず，データそのものから学習信号を生成する技術である．例えば，「文中の一部の単語を隠してその単語を予測する」や「画像とテキストの対応関係を学習する」といった方法が用いられる．

重要な技術的概念として，埋め込み空間（Embedding Space）がある．モデルは，入力データを高次元ベクトル空間上の点として表現し，意味的に類似したデータが近くに配置される．視覚言語統合モデルは，画像とテキストを共通の埋め込み空間にマッピングする技術であり，CLIP はその代表例である．対照学習により，正しいペアの埋め込みベクトル間の距離を近づけ，誤ったペアの距離を遠ざけることで，視覚概念と言語概念の対応関係を学習する．

\section{ゼロショット物体検出}
ゼロショット物体検出とは，学習時に見たことのない物体カテゴリを，テキスト記述のみで検出する技術である．従来の物体検出では，あらかじめ定義された固定カテゴリのみを検出可能であったが，ゼロショット検出は視覚情報と言語情報を統合することで，任意のテキストプロンプトに対応した柔軟な検出を実現する．

この技術の核心は，物体の視覚的特徴と言語的記述を共通の埋め込み空間で対応付けることにある．画像は CNN または Vision Transformer により処理され，多スケールの特徴マップが生成される．テキストプロンプトは BERT などの言語モデルによりエンコードされ，言語特徴ベクトルに変換される．視覚特徴と言語特徴は，cross-attention 機構により相互作用する．言語特徴の各単語が画像特徴の各位置に対して attention 重みを計算し，テキストプロンプト全体に対応する画像領域が特定される．

Grounding DINO は，この技術を実装した代表的なモデルである．入力画像が Swin Transformer により処理され階層的な視覚特徴が抽出され，テキストプロンプトが BERT により言語特徴に変換される．これらの特徴が特徴強化モジュールで相互に強化された後，Transformer デコーダにより物体クエリが生成される．各物体クエリは，bounding box の座標とクラススコアを予測する．

推論時には，ユーザーが任意のテキストプロンプトを入力でき，単一物体の記述から属性を含む記述，関係性を含む記述まで対応可能である．信頼度スコアが閾値（通常 0.3～0.5）を超える検出のみが最終結果として採用される．

\section{ゼロショットセグメンテーション}
セグメンテーションとは，画像内の各ピクセルに対して所属する物体または領域を識別する技術である．ゼロショットセグメンテーションは，学習時に見たことのない物体に対しても，プロンプトに基づいて高精度なマスクを生成する技術である．

Segment Anything Model (SAM) は，プロンプタブルセグメンテーションを実現する基盤モデルであり，点，bounding box，マスクの3種類のプロンプトに対応する．そのアーキテクチャは，画像エンコーダ，プロンプトエンコーダ，マスクデコーダの3つのコンポーネントから構成される．
画像エンコーダは Vision Transformer をベースとし，入力画像を 16×16 ピクセルのパッチに分割して処理する．self-attention 機構により各パッチは画像全体の文脈情報を考慮した表現を獲得し，画像埋め込みが生成される．プロンプトエンコーダは，異なる形式のプロンプトを統一的な表現に変換する．点プロンプトは位置エンコーディングにより，テキストプロンプトは CLIP の言語エンコーダにより高次元ベクトルに変換される．
マスクデコーダは，Transformer ベースのアーキテクチャを採用し，双方向の cross-attention により画像埋め込みとプロンプト埋め込みを融合する．出力は画像と同じ解像度を持つバイナリマスクであり，SAM は複数の候補マスク（通常3つ）を同時に出力する．これは曖昧なプロンプトに対して複数の妥当な解釈を提示するためである．

Language Segment-Anything (Lang-SAM) は，Grounding DINO と SAM を統合したゼロショットセグメンテーションシステムである．テキストプロンプトが Grounding DINO に入力され対応する物体の bounding box が検出され，この bounding box が SAM のプロンプトとして使用され高精度なセグメンテーションマスクが生成される．
